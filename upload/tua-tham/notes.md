# File:Tua Tham.png → SVG

"Tua Tham", the name of the Tai Tham script in Tai Tham: ᨲ᩠ᩅᩫᨵᩢᨾ᩠ᨾ᩼, as one real `<text>` in Noto Sans Tai Tham.
- The text is from en.wikipedia Help:Multilingual support, which shows this image beside it.
- It is fitted to the PNG's ink box by `tools/glyph_specimen.py`.
- The PNG is set in a calligraphic Lanna face, so the shapes differ (ink IoU 0.08), but the letters and their
  arrangement are the same.
- I also tried SIL's Payap Lanna, which is closer in style, but its marks shaped wrongly in the test renderer, and it
  is less likely to be installed where the SVG is rendered.

Local render fonts: `data_lake/downloads/fonts/noto-tai-tham/` and `data_lake/downloads/fonts/payap-lanna/` (both
OFL). Comparison: `Documents\claude-screenshots\agentic-vectorization_2026-10-20\cmp_tua-tham.png`.
