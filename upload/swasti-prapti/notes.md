# File:Swasti Prapti ring Wikipédia Basa Bali.png → SVG

"Swasti prapti ring Wikipédia basa Bali" (welcome to the Balinese Wikipedia) in Balinese script as one real `<text>`:
᭚ᬲ᭄ᬯᬲ᭄ᬢᬶᬧ᭄ᬭᬧ᭄ᬢᬶᬭᬶᬂᬯᬶᬓᬶᬧᬾᬤᬶᬳᬩᬲᬩᬮᬶ
- The text is from en.wikipedia Help:Multilingual support, which shows this image beside it. The closing ᭟ is left
  out, as in the PNG.
- It is set in Noto Sans Balinese and fitted to the PNG's ink box by `tools/glyph_specimen.py`.
- The glyphs match one for one. The PNG's own font draws the opening ᭚ and some letters with different flourishes,
  and its strokes are hairlines, so ink IoU is only 0.19.
