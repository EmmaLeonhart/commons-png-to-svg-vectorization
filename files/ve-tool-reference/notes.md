# File:VisualEditor tool reference-ltr.png → SVG

A VisualEditor onboarding illustration, built by construction (`files/ve-tool-reference/build.py`). Every coordinate
is measured in the PNG:
- **The article page:** a frame, a grey side panel with its circle, a T and text lines, and two yellow highlights.
  Each highlight holds a quote mark and a reference number, [1] or [2], as real `<text>`.
- **The links:** blue lines from the references to the sources.
- **The sources:** line art of an open book (covers, pages, spine, page lines) and a newspaper (page, rolled edge,
  header bar, picture box, text lines).

The original was a PNG in the VisualEditor repository too, so it has no SVG source. The book and newspaper icons on
Commons (OOjs UI) are newer, solid designs.
